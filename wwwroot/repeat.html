Search with your own YouTube key

Pasting links always works. To also search by name, add a free YouTube Data API key (about 5 minutes, once).

  1. Open console.cloud.google.com and sign in with your Google account.
  2. At the top, open the project picker → New project. Name it On repeat, press Create, then make sure it's the selected project.
  3. Open YouTube Data API v3 in the API Library and press Enable.
  4. Go to APIs & Services → Credentials → + Create credentials → API key. Copy the key; it starts with AIza.
  5. Recommended: open the key's settings → API restrictions → Restrict key → tick YouTube Data API v3 → Save. Then the key can't be used for anything else.
  6. Paste it below and press Save. The app checks it with Google before keeping it.

Free daily quota: 10,000 units. A search costs 100, so about 100 searches a day. The key stays on this PC, in %APPDATA%\RepeatDesktop\settings.json.
